# تغییرات اعمال شده

## افزودن قابلیت ورود متن ساده به پایگاه دانش

در این به‌روز‌رسانی، قابلیت جدیدی به API اضافه شده است که به کاربران امکان می‌دهد متن ساده را مستقیماً به پایگاه دانش وارد کنند. تا پیش از این، تنها راه ورود داده به پایگاه دانش، استفاده از URL‌ها بود.

### فایل‌های تغییر یافته

1. **api/models.py**
   - افزودن کلاس `PlainTextRequest` برای مدیریت درخواست‌های ورود متن ساده
   - این کلاس شامل فیلدهای زیر است:
     - `text`: متن اصلی (اجباری)
     - `title`: عنوان (اختیاری)
     - `source`: منبع متن (اختیاری)

2. **api/main.py**
   - افزودن اندپوینت جدید `/api/add_plaintext` برای دریافت و پردازش متن‌های ساده
   - پیاده‌سازی منطق پردازش متن و افزودن آن به پایگاه دانش
   - ذخیره پشتیبان از متن‌های دریافتی در دایرکتوری `data/plaintext_data`
   - اطمینان از اینکه اندپوینت `/api/all_knowledge` می‌تواند داده‌های اضافه شده را بازیابی کند

3. **scripts/test_add_plaintext.py**
   - ایجاد اسکریپت تست برای بررسی عملکرد اندپوینت جدید
   - تست افزودن یک متن نمونه به پایگاه دانش
   - تست بازیابی داده‌های اضافه شده با استفاده از اندپوینت `/api/all_knowledge`

### نحوه استفاده

برای افزودن متن ساده به پایگاه دانش، می‌توانید درخواست POST زیر را به API ارسال کنید:

```bash
curl -X POST "http://localhost:8001/api/add_plaintext" \
     -H "Content-Type: application/json" \
     -d '{
         "text": "متن مورد نظر برای افزودن به پایگاه دانش",
         "title": "عنوان متن (اختیاری)",
         "source": "منبع متن (اختیاری)"
     }'
```

### نکات مهم

1. متن دریافتی به صورت خودکار پردازش شده و به قطعات (chunks) مناسب تقسیم می‌شود.
2. هر قطعه متنی با متادیتای مربوطه در ChromaDB ذخیره می‌شود.
3. برای هر متن اضافه شده، یک نسخه پشتیبان در مسیر `data/plaintext_data` ذخیره می‌شود.
4. داده‌های اضافه شده بلافاصله در پایگاه دانش قابل جستجو خواهند بود.
