# چت‌بات پشتیبانی ساتیا

این پروژه یک چت‌بات هوشمند برای پشتیبانی از مشتریان ساتیا است که از تکنولوژی RAG استفاده می‌کند.

## ویژگی‌ها
- استخراج خودکار داده‌ها از وبسایت ساتیا
- پشتیبانی از محتوای چندرسانه‌ای (متن، تصویر، PDF)
- جستجوی معنایی پیشرفته
- پشتیبانی از زبان فارسی
- ذخیره‌سازی و بازیابی کارآمد داده‌ها

## ساختار پروژه
```
satya_chatbot/
├── crawler/           # ماژول استخراج داده
├── data/             # داده‌های خام
├── models/           # مدل‌های پردازش متن
├── database/         # مدیریت پایگاه داده
├── api/              # API سرور
└── utils/            # ابزارهای کمکی
```

## نصب و راه‌اندازی
1. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

2. تنظیم متغیرهای محیطی:
- کپی کردن `.env.example` به `.env`
- تنظیم مقادیر مناسب در `.env`

3. راه‌اندازی پایگاه داده:
```bash
python -m database.setup
```

4. استخراج داده‌ها:
```bash
python -m crawler.main
```

5. راه‌اندازی سرور:
```bash
uvicorn api.main:app --reload
```

## استفاده
API در آدرس `http://localhost:8000` در دسترس است.

## مستندات
مستندات کامل API در `/docs` در دسترس است.
